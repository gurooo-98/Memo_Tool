# Memo Tool

TODO, 일정, 이슈를 한곳에서 정리하는 개인용 메모 도구입니다.

브라우저 내부 데이터에 의존하지 않고, 사용자가 선택한 로컬 폴더에 항목별 JSON 파일을 저장합니다.

## 주요 기능

- TODO 관리
  - `NOW`, `NEXT UP`, `SOMEDAY` 태그로 할 일 분류
  - 완료 항목을 별도 관리 영역으로 이동
  - 수정·삭제 및 등록 시각 확인
- 일정 관리
  - 월간 캘린더, 기간 일정 가로 표시
  - 파스텔 7색 일정 분류
- 이슈 관리
  - 제목과 자유 태그(`#MEDIA`, `#FS` 등) 입력
  - 긴 본문을 위한 전용 이슈 작성 화면
  - 제목 실시간 검색 및 태그 필터
  - AI 요약 기능이 연결될 자리 제공
- 로컬 파일 저장
  - TODO·일정·이슈 각각을 개별 JSON 파일로 저장
  - 수정 시 파일 갱신, 삭제 시 해당 파일 삭제

## 기술 구성

- HTML
- CSS
- JavaScript
- File System Access API

Python, 데이터베이스, 외부 서버를 사용하지 않습니다.

## 사용 방법

1. Chrome 또는 Edge에서 `main.html`을 엽니다.
2. 첫 화면에서 **저장 폴더 선택**을 누릅니다.
3. 데이터를 보관할 상위 폴더를 선택하고 쓰기 권한을 승인합니다.
4. 선택한 폴더 안에 `Memo_Tool_Data` 폴더가 생성됩니다.

> 브라우저 보안 정책상, 앱을 다시 열면 저장 폴더를 다시 연결해야 할 수 있습니다.

## 파일 저장 구조

```text
Memo_Tool_Data/
├── todos/
│   ├── {todo-id}.json
│   └── ...
├── schedules/
│   ├── {schedule-id}.json
│   └── ...
└── issues/
    ├── {issue-id}.json
    └── ...
```

각 항목은 고유 ID를 가집니다. 이 ID는 TODO·일정·이슈의 등록 또는 수정 화면에서 확인할 수 있습니다.

## 브라우저 지원

로컬 파일 저장 기능은 File System Access API를 사용합니다.

- 권장: Chrome, Edge
- 지원이 제한될 수 있음: Firefox, Safari

## 실행 시 참고

이 프로젝트는 서버 없이 동작하도록 작성되었습니다. 다만 브라우저 환경에 따라 `file://` 방식의 기능이 제한될 수 있으므로, 로컬 파일 저장 선택 창이 열리지 않는 경우 Chrome 또는 Edge에서 실행해 주세요.
